🌌 E. Horizon
E. Horizon is a full-stack event management and ticket booking platform that enables users to discover, explore, and book events seamlessly. The platform provides secure authentication, event management, seat tracking, and booking functionality through a modern and responsive user interface.

🚀 Live Demo
🔗 https://e-horizon.vercel.app

⚙️ Installation
Clone Repository
git clone https://github.com/IshantSingh27/E.-Horizon.git
cd E.-Horizon
Install Dependencies
npm run install:all
Run Development Server
npm run dev
Frontend:

http://localhost:5173
Backend:

http://localhost:5000
🔑 Environment Variables
Create a .env file inside the server directory.

PORT=5000

MONGODB_URI=your_mongodb_connection_string

JWT_SECRET=your_jwt_secret

EMAIL_USER=your_email

EMAIL_PASS=your_email_password
